# You have been tasked with fixing a bug in an open source project on GitHub called IntelliFlux. This project has a public has a repository and the fix should be submitted as a pull request. You do not have direct access to the IntelliFlux repository.


1. Fork IntelliFlux into your own GitHub account
2. Clone the IntelliFlux repository from your GitHub account
3. Create a branch on your local repository
4. Fix the bug by editing the code on your machine
5. Create a commit
6. Push your changes to GitHub
7. Create a pull request

Correct order listed above, though I also accepted #3 coming after #4 or #5.
